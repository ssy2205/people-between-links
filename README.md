# 사람 사이의 링크

2026 전국 대학생 생명존중 광고공모전의 `한국생명존중희망재단 가치 확산 광고` 출품을 위해 만든 스크롤형 랜딩페이지입니다.

## 포함된 기능

- `관심이, 도움에 닿도록.` 메시지의 6개 패널 랜딩
- 300×250 / 160×600 배너 시안 전환
- 현재 규격 배너 PNG 다운로드
- 공식 공모전·재단 링크
- 제출 준비도 체크리스트
- 링크 공유용 `public/og.png`

## 실행

```bash
npm install
npm run dev
```

## 제출 전 교체할 것

주최 측이 허용한 공식 재단 로고와 최신 사업 표기를 받으면 배너·랜딩의 교체 자리만 최종 조판합니다. 관련 기획서와 체크리스트는 상위 작업 폴더의 `outputs/`에 정리되어 있습니다.
